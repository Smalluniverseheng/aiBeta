## 版本号修正历史（2026-07-23）

### 问题
原 `js/changelog.js` 存在跳版本（1.0→1.4 缺少 1.1/1.2/1.3）、版本号不连续、日期混乱等问题。

### 修正规则
1. 从 1.0 开始，每次 +0.1，连续编号
2. 里程碑（major=true）：x.0 版本 + 创立(1.0) + 首次部署(1.1)
3. 日期：1.0 = 2026-06-10（创立），1.1 = 2026-07-10（部署），后续顺延
4. 严格 `x.y` 格式，禁止 `x.y.z`

### 当前版本
- **前端版本**：v4.3（2026-07-24）
- **代码版本对齐**：providers.js / index.html / sw.js 统一为 4.3
- **changelog.js 最新**：4.2（4.3 的 changelog 记录待补）

## 重大架构决策

### 2026-07-22 — 后端架构（v2 分支）
- 决定保留纯前端主分支，后端以 Cloudflare Worker + Supabase 形式附加
- Worker 代码写在 `AI` 仓库的 `v2` 分支，**不在 aiBeta**
- 前端通过 `api.js` 的 `CONFIG.BACKEND_URL` 接缝接入

### 2026-07-23 — 分支整改
- `main`（原 gh-pages 功能）→ `production`（正式版默认分支）
- `gh-pages` → `preview`（正式版 Pages 部署分支）
- aiBeta 仓库独立出来作为测试沙盒，默认分支 `main`

### 2026-07-23 — 手表端重构
- 侧边栏改为 Kimi 式抽屉（右滑开/左滑关）
- 占 80% 宽度，右侧露出 1/5 对话内容
- 长按菜单、多选管理、自动关闭抽屉

### 2026-07-24 — 排行榜独立化
- 从发现页内嵌折叠改为独立页面
- 左侧 11 分类导航，右侧图表 + 榜单
- 综合榜 50 名 + 10 个分类榜单
