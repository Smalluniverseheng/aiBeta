# 手表端开发规范

---

## 设备检测

```javascript
// js/device.js
const isWatch = () => {
  const ua = navigator.userAgent;
  const width = window.innerWidth;
  const height = window.innerHeight;
  return /Watch|AppleWatch|Wear\s*OS/i.test(ua) ||
    (width <= 340 && height <= 340);
};
```

检测后会在 `<html>` 上设置 `data-device="watch"`。

---

## CSS 隔离

所有手表端样式必须用 `html[data-device="watch"]` 前缀：

```css
/* ✅ 正确 */
html[data-device="watch"] .sidebar {
  width: 80%;
}

/* ❌ 错误 */
.watch .sidebar {  /* 不要这样写 */
  width: 80%;
}
```

## 布局规范

```
┌─────────────────────────┐
│ [头像] 小宇宙  Allegretto [扫一扫] │  ← 点击头像 = 跳转"我的"
├─────────────────────────┤
│ 🖥 模型                 │  ← 点击跳转模型页
│ 📦 其他                 │  ← 点击跳转发现页
├─────────────────────────┤
│ 💬 读取项目信息留言       │  ← 历史会话（可上下滚动）
│ 🧅 洋葱细胞液浓度实验     │
│ ...                     │
├─────────────────────────┤
│ [🔍 搜索历史会话…]  [+]  │  ← 底部搜索+新建
└─────────────────────────┘
```

- sidebar 占 **80%**，右侧露出 **1/5** 对话内容
- 点击历史对话 → 加载并**自动关闭抽屉**
- 长按历史对话（500ms）→ 弹出菜单

---

## 交互规范

| 手势 | 效果 |
|------|------|
| 右滑（屏幕左边缘） | 打开 sidebar 抽屉 |
| 左滑（抽屉内） | 关闭抽屉 |
| 点击历史对话 | 加载该对话，关闭抽屉 |
| 长按历史对话（500ms） | 弹出菜单：重命名/置顶/多选/删除/取消 |

---

## 样式规范

- 按钮最小 **36×36px**
- 字号最小 **12px**
- 历史记录项隐藏 `meta`（时间）节省空间
- 删除按钮隐藏，改成长按菜单
- 简化动画，减少性能消耗

---

## 功能限制

- **强制单模型模式**（隐藏辩论/协同/多模型）
- **语音优先**：麦克风按钮常驻底部中央
- **单次滚动一屏**
- 圆屏安全边距：`env(safe-area-inset)`

---

## 已知问题

- Service Worker 会缓存旧版本，测试时需清除缓存或换端口
- 手表端屏幕极小，所有交互必须考虑误触
- 长按时间 500ms，太短会误触发，太长用户不耐烦
